# Electrical_Physics_Labs
Repositório dedicado às disciplinas de Eletricidade e Laboratórios de Física, incluindo Eletricidade Básica, Análise de Corrente Contínua (ACC), Sistemas Microcontrolados, Eletrônica, Circuitos Digitais e Física 1, 2 e 3. Destacam-se uma apresentação desenvolvida em Python para ACC e códigos em C para Eletrônica e Sistemas Microcontrolados.
